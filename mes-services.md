## Service 1 — Développement d'applications web full-stack
- Description : applications web complètes, de l'interface au serveur et à la base de données.
- Problème résolu : processus manuels (Excel, cahiers) transformés en application accessible partout.
- Technologies : Java, Spring Boot, React ou Angular, MySQL/PostgreSQL, Git
- Exemple : application de gestion des stocks avec tableau de bord et comptes utilisateurs.
- Client cible : PME, commerçants, startups de Douala et d'Afrique francophone
- CTA : « Décrivez votre besoin en 5 lignes — proposition technique sous 24 h. »

## Service 2 — Conception d'APIs REST & bases de données
- Description : APIs REST et bases relationnelles propres et documentées.
- Problème résolu : stocker, organiser et servir les données de façon fiable pour un site ou une app.
- Technologies : Spring Boot ou Flask, MySQL, PostgreSQL, GitLab
- Exemple : API de gestion des commandes pour une entreprise de livraison.
- Client cible : startups, devs solo, entreprises en digitalisation
- CTA : « Vous avez déjà une maquette ou un front-end ? Je construis l'API qui la fera vivre. »

## Service 3 — Maquettage UI/UX & prototypage Figma
- Description : maquettes et prototypes interactifs avant développement.
- Problème résolu : visualiser et valider le produit avant d'investir dans le développement.
- Technologies : Figma
- Exemple : prototype cliquable d'app de réservation, testé avec des utilisateurs.
- Client cible : porteurs de projet, startups en idéation
- CTA : « Obtenez un prototype cliquable en quelques jours — contactez-moi pour cadrer. »

## Service 4 — Intégration & développement front-end
- Description : conversion de maquettes en pages web responsives.
- Problème résolu : un design existant codé proprement et fonctionnel.
- Technologies : React, Angular, HTML/CSS/JavaScript
- Exemple : site vitrine dynamique avec formulaire relié à une base de données.
- Client cible : designers, agences, indépendants
- CTA : « Envoyez votre maquette — devis et délai sous 24 h. »

## Service 5 — Préparation au déploiement & Docker (en consolidation)
- Description : mise en conteneurs pour environnements de test et démo reproductibles.
- Problème résolu : « ça marchait sur ma machine » — un environnement identique partout.
- Technologies : Docker, bases de GitLab CI, Linux
- Exemple : application Spring Boot packagée, déployable en un clic pour une démo.
- Client cible : projets en démonstration, livraisons propres
- CTA : « Votre application est prête ? Je la prépare pour une démo fiable. »
- Note honnêteté : proposé pour des besoins simples uniquement.
